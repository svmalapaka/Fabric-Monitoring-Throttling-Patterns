Monitoring Dashboards

Monitoring dashboards in Fabric provide visual insights into workload performance, capacity usage, and system health. They help you quickly see which items or workspaces are driving resource consumption.

Typical monitoring views include:

  • Workspace-level performance and activity
  • Item-level metrics for pipelines, notebooks, and reports
  • Historical trends of CU usage and workload volume

Using these dashboards regularly allows you to spot patterns, identify bottlenecks, and plan capacity changes or workload adjustments.
