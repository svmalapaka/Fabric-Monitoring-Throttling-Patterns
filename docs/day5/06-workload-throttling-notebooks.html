Notebook Throttling

Notebooks can be throttled when their sessions consume excessive compute or when many notebooks run concurrently on the same capacity. Throttling may appear as slower cell execution or delayed session start.

Common notebook throttling patterns:

  • Cells taking longer to execute under load
  • Sessions waiting for resources before starting
  • Resource limits affecting large joins or aggregations

To mitigate notebook throttling:

  • Break large jobs into smaller, more efficient steps
  • Avoid running many heavy notebooks at the same time
  • Use monitoring to understand peak usage periods
