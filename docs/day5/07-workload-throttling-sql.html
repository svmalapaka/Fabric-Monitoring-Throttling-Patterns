SQL Endpoint Throttling

SQL endpoints can be throttled when query workloads place sustained pressure on the underlying warehouse. Throttling may show up as slower query response times or temporary limits on concurrent queries.

Typical SQL throttling behaviors:

  • Queries taking longer to complete during peak usage
  • Reduced concurrency for heavy analytical queries
  • Timeouts or resource limit messages for extreme workloads

To reduce SQL throttling:

  • Optimize queries and indexes where applicable
  • Avoid running many complex queries simultaneously
  • Use monitoring to identify high-pressure time windows
